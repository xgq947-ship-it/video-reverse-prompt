# ACTING SYSTEM(表演系统)
## 面向 AI 视频生成的角色表演(Seedance 2.0)

你读到这份文档,是因为你的用户正在生成电影级 AI 视频,需要你在他们的 prompt 中写出**角色表演(character acting)**。请研读本文档,之后每次撰写、审阅或修正视频生成 prompt 的表演层时都应用它。本文件在格式上与具体模型无关:无论你的用户使用哪种 prompt 模板,你产出的表演内容都应进入 prompt 中运动 / 角色行为 / 表演(performance)的部分。

**整个系统的核心公理:表演(acting)是压力下的行为(behavior),而不是情绪展示。**角色想要某样东西,有东西挡在中间,于是他们采取行动去得到它。情绪是这场挣扎的副产品——绝不是你直接写的东西。以下所有内容都在展开这条规则。

---

# 第一部分——技艺:什么是好的表演

## 1. 定义

表演是在虚构情境下的真实行为(Meisner)。不是描绘情绪,不是背诵台词,不是"表情丰富"。画面里的人想要某样东西,有东西**干扰**他们,于是他们**行动**去得到想要的。

| 糟糕的表演(Bad acting) | 好的表演(Good acting) |
|---|---|
| 展示情绪("我很生气") | 追逐目标("我会让你把钱还回来")——愤怒自然涌现 |
| 等着接自己的台词 | 每一秒都在倾听并回应对手戏演员 |
| 身体为语言配图(手势=词语) | 身体过着自己的生活,有时与语言相矛盾 |
| 所有台词一个节奏一个调子 | 每次战术变化,节奏随之改变 |
| 情绪在台词处开启、之后关掉 | 状态是连续的——台词之前有"前史",之后有"后史" |
| 脸在"表演"——挑眉、做鬼脸 | 脸在思考——话未出口,想法已从眼神中读出 |

## 2. 每个场景的五大支柱

每个场景中的每个角色都可以分解为五个要素。只要缺一个,表演就会垮掉。

**2.1 目标(Objective)。**角色在**这个场景里、此刻、针对某个具体的人**想要什么。永远是一个指向对手戏演员的动词:"让他招供"、"乞求宽限一周"、"让她相信我不害怕"。绝不是一种状态("生气"、"愧疚")——状态无法直接表演。场景目标背后是贯穿目标(super-objective)——角色在整个故事中想要的东西;每个场景目标都是走向它的一步。

**2.2 障碍与赌注(Obstacle & stakes)。**什么阻止他们得到想要的东西——外在的(另一个角色想要相反的东西;房间里有人目击;离截止时间还有两小时)或内在的(自尊心不允许他乞求;他们自己都不信自己的话)。赌注:失败的成本越高,场景越绷紧。永远回答"如果我得不到我想要的,会发生什么?"——答案必须让角色害怕。

**2.3 战术(Tactics)。**此刻追求目标的具体方法。战术是动作动词:施压、讨好、羞辱、恳求、挑衅、讨价还价、威胁、拖延。当一种战术失败时,一个活人会**换一种**。死板的表演是一个场景从头到尾只用一种战术。

**2.4 节拍(Beats)。**节拍是最小的动作单位:角色想着一件事、用一种方式追求它的那一段。节拍在以下时刻结束:目标达成、战术失败、新信息到来、或权力平衡发生转变。**每一次节拍变化都必须体现在行为上**:一个停顿、一次体态变化、语速的变化、目光的转移。一个好场景有 2–4 次节拍变化;如果整个过程中行为一成不变,这个场景就是平的。

**2.5 潜台词(Subtext)。**角色真正想的、想要的,与他嘴上说的相反。潜台词不是表演出来的——当角色说着假台词、演着真目标时,它会自己泄露出来。可以写进场景的标记:不是问题的问题;重复(反复问同一件事——因为不相信答案);突兀的话题切换;不合时宜的玩笑(用来遮掩脆弱);过于简短的回答("没事。""行。"——一扇关上的门)。

## 3. 倾听与反应——质量的主要检验

表演不在台词里,而在台词的**缝隙之间**。你应该写进场景的真实倾听的可观察标记:

1. **反应在对手台词结束之前就已开始。**一个人说到半句,听者已领会要点——脸和身体已经在回应。对手台词结束前始终面无表情、到点才"开机",是死表演。
2. **先想后说。**回答难题之前有一个微停顿——人明显地"决定"要说什么。匀速的即时回答 = 背好的台词,没有生命。
3. **评估时刻(The assessment moment)。**当重要的事情发生(消息、威胁、侮辱)时,角色需要时间消化——从零点几秒到长长的停顿。电影就活在这些评估的特写里:一张脸、失焦的目光、晃动的世界。
4. **来自对手的传染。**节奏、音量与能量随对手而变化:一声吼叫,回应要么是对吼,要么是有指向的安静——但一定是回应,而不是被盖过去。

## 4. 身体:角色的物理生活

**4.1 物理状态先于心理。**身体在开口之前就把故事讲完了。为每个角色设定这些参数:

- **重心:**高(胸部、下巴——自信、攻击性、地位)或低(肩膀、驼背——疲惫、恐惧、顺从)。
- **节奏(Tempo):**快/凌乱(紧张、兴奋剂式的能量)或慢/经济(掌控、威胁——最危险的人动得最少)。
- **开放度:**挺直的肩与张开的掌 vs 抱臂、低垂的头、封闭的姿态。
- **呼吸:**又高又急(恐慌)vs 又低又慢(掌控)。呼吸是状态最诚实的指标;憋住的呼吸 = 憋住的表演。声音与物理必须匹配:刚跑完步的人不可能用平稳的声音说话。

**4.2 事务(Business)——身体任务。**角色几乎总需要一件"正在做的事":他们不是"在聊天",而是在修引擎、数钱、做饭、擦杯子——然后在做这些事的同时说话。事务杀死虚假的舞台腔(双手忙着真实的事),制造场景节奏(停顿被动作填满),并生成潜台词(一个人**怎么**数钱,比他说什么更有信息量)。**动作中断法则:**最强的重音是角色**停下**手头的事。如果他在切面包,说到某一句时停住了——那句话就成了事件。把"停下"用作标点。

**4.3 空间关系学(Proxemics)——距离即戏剧。**角色之间的距离是他们关系的可见图谱:亲密距离(0.5 米以下)——爱或暴力,未经邀请进入即是侵犯,在脸前 10 厘米处低声的威胁比隔着房间吼叫更可怕;个人距离(0.5–1.2 米)——信任;社交距离(1.2–3.5 米)——公事、戒备;公共距离(3.5 米以上)——疏离、层级。场景的戏剧性常常就是距离的故事:谁靠近,谁打破,谁僵住。**距离的变化 = 节拍的变化。**

**4.4 地位(Status)——看不见的等级。**地位是你**做**什么,不是你**是**什么。高地位:头部不动、动作缓慢、目光长久、回答前停顿、占据空间、碰别人的东西。低地位:坐立不安、频繁触碰自己(脸、头发)、说话破碎、陪笑、用眼神请示许可。表演中最有趣的东西是**地位断裂(status breaks)**——露出恐惧一秒的老板;突然不笑了的下属。一个有力的场景形状:高调进入然后崩塌,或低调进入然后翻转全场。

## 5. 台词:好的表演听起来什么样

- 节奏写在文本里——精确地呈现它;快 ≠ 含糊。
- 重叠是正常的(台词踩着彼此的尾巴),但关键词保持清晰。
- **音量对比:最可怕的话是用最轻的声音说出来的。**喊叫是弱者的货币;掌控场景的角色会降低音量,所有人都凑近去听。
- 停顿是事件,不是空洞:只有停顿内部发生了点什么(一次评估、一个决定、拒绝回答),这个停顿才是合法的。
- 真实的话语有杂质:被打断、含混的字词、重复、没说完整的句子。完美构造的句子会杀死街头的真实。

# 第二部分——写表演:prompt 架构

## 6. 角色表演主档案(master profile)

每个反复出现的角色都有一份主档案——关于他如何表演的永久真相来源。它只写一次,然后按场景适配(见第 8 节)。目标长度:**150–220 字,一段连贯的行文**,全部用中文书写(专业术语保留英文原词),完全可观察、可拍摄。

**模板(区块顺序固定):**

```
角色 acting:[名字]。[年龄、体格、体型、体态——身体是其人生经历的档案]。[心理引擎,用一句话概括——解释其身体语言的内在驱动力]。声音档案:[音高/音色、口音/出身、语速与说话方式,以及情绪之下声音如何破音或变化]。关键身体习惯与小动作:[标志性小动作及其触发条件;压力小动作及其触发条件;掩饰行为——他们如何隐藏自己的感受;面部面具及其崩裂的确切条件]。走路方式:[以步态塑造角色——命名且具体,写明重心、节奏与落脚方式]。然而,当[情绪触发点]时,[转变——体态、步态与面部如何变化]。[可选:软化目标——唯一能让那张脸真正柔和下来的人或物]。
```

**每个区块的写作规则:**

1. **只写可观察的行为。**每一个内在状态都必须有身体标记。绝不写"他很紧张"——要写下唇颤抖、沉重的吞咽、从嘴里长吸一口气再噘唇急呼。
2. **每个小动作都有触发条件。**不写"他掰指节",而写"他在无聊的对话中掰指节,以假装自信"。格式:[小动作] + [何时/为何]。没有触发条件的小动作是装饰;有触发条件的小动作才是戏剧性。
3. **给步态命名。**引号内的、令人印象深刻的命名会锚定生物力学:"权力式大步"(power-walk)、"孔雀式踱步"(peacock strut)、"画廊漫步"(gallery walk)、"攻城锤式步伐"(battering-ram stride)、"无畏舰式步调"(dreadnought pace)。然后展开它:重心、脚步、躯干和手臂做什么、头做什么。
4. **同时构建面具与裂痕。**档案中最具电影感的手法是有条件的转变:面具,以及让它崩塌的确切触发点。被拒绝时,傲慢的昂首阔步崩塌成孩子气的萎靡;提到家人时,大嗓门脸上闪过恐慌的自卑;面对某一个人时,严厉的纪律融化成灿烂的微笑。**每份档案至少带一句"However, when X——……"式的转折句。**一个同时演出两种真相的角色,是木偶与人的区别。
5. **一个软化目标。**在角色合适的情况下,给这张脸恰好一个人、动物或物件,让它真正为之软化。一个——不是两个。这让人性化而不稀释。
6. **不写服装。**衣物与服饰住在 prompt 的场景/外观区块里,绝不在表演档案中。档案必须经得起任何换装。
7. **不写镜头、不写色彩。**表演只驱动表现、面部、声音与动作。镜头、调色与灯光在 prompt 的其他地方。
8. **体格承载生平。**年龄、体格与体态的选择是为了讲出前史:一副"被过往挣扎磨损"的体格、一双"永远绷紧"的肩膀、一种"为撑出权威而过度矫正"的姿态。身体是一份文档——职业、旧伤与自我形象都必须从中读出来。

## 7. 眼神的生命——每份档案、每个场景的必需项

死气沉沉的眼睛是 AI 生成表演的头号破绽。给每个角色持续、自然的眼部生命:

- **微扫视与目光定位(micro-saccades and gaze targeting)**指向他们注意的人或物;目光持续移动——眼睛游移、思考时撇开、扫向某个细节再落回来。它们绝不会僵死地锁定在单一一点。
- **真实的眨眼频率与质量**,与状态挂钩:压力下快速连眨;掌控中缓慢平静的眼睑;在失神的瞬间"眨一下再呆住"。
- **鲜活的眼中高光(catchlights)**——眼睛必须看起来湿润、有光、是活的。
- **受控的静止是选择,绝不是死寂。**如果一个角色的调性是近乎不眨眼的掠食者式平静,就让眨眼稀少、缓慢、有意识——这是一个决定,而不是僵住——并让目光仍然带着意图缓慢移动。
- **眼睛引领思想。**眼睛比头的转动先一刻抵达目标。话未出口,思想已从眼睛里读出。
- **眼神的生命随节拍反应**,像所有其他行为一样:眨眼频率、目光稳定度与高光的温度,都会在节拍变化时变化。

## 8. 场景适配——主档案是重写,不是粘贴

主档案是角色**是谁**。对每个场景,把它**重写**进当下:

1. **只写在场角色。**只为实际出现在画面里的角色写表演段落。画面里没有的角色 → 没有段落。
2. **保留恒定内核。**身份、声音档案、标志性小动作、眼神生命与情绪主线在每个场景中保持不变——这是让角色跨越剪辑保持一致的东西。绝不与主档案矛盾。
3. **为这个场景重新表达。**选择、强调、调整或删去具体行为,以适配场景的体态(坐/站/跑/躲)、动作与节拍、情绪状态和一天中的时刻。
4. **转化,而不是删除。**本场景中物理上无法发生的行为,是转化而不是移除:一个不安的踱步者瘫坐在沙发上,保留同样紧张的引擎,只是转移为不安的微晃、甩手腕和撕纸。能量恒定;出口改变。
5. **一段连贯的行文。**把适配折叠进角色调性的散文里——prompt 内部不要项目符号、不要标题、不要"旋钮"式的说明行。
6. **如果你的流水线使用素材引用,以角色的引用标签开头**,让模型把表演绑定到正确的人身上。

## 9. 声音:固定身份,永不适配

表演按场景重写;**声音是锁定的**。每个角色有一条 Voice prompt——他永久的嗓音身份。当角色有台词时,把 Voice prompt **逐字**粘贴进 prompt 的音频/声音字段。绝不为场景修改它。如果角色出场但没有台词,则省略它。

**Voice prompt 公式(1–2 句,加引号):**

```
"一位[年龄]岁的[出身/口音描述]。[音色与音域];[语速与说话方式];[情绪特质——以及在压力下如何变化]。"
```

表演段落**内部**的声音档案描述的是说话在戏剧上如何表现(节奏变化、破音、耳语);音频字段里的 Voice prompt 锁定的是声音本身。两者必须彼此一致。

## 10. 状态,而非过渡

视频生成模型在过渡上失败,在状态上成功。描述已经**处于**动作状态中的角色——投掷中、出拳中、踱步中、争吵中——而不是到达那里的过程("伸手进包里、掏出来、蓄力"会崩掉;"投掷中,手臂伸展"则立得住)。按节拍链式地写状态,而不是叙述连续的过程。

## 11. 群戏与空间

- **群体反应像波浪一样传导,从不整齐划一。**第一个人先听懂笑话,第二个慢半拍,第三个根本没懂。同时发生的相同反应看起来是假的(除非故意编排的喜剧性同步正是目的)。
- **反应比动作更值钱。**每个事件之后,最值钱的画面是目击者的脸。
- **在威胁前定格。**群像持续地微动——转移重心、打手势、侧身——而在关键威胁出现时,一切都**停住**。喧嚣→静止的对比就是标点。
- **动线 = 动机。**没有人会无缘无故穿过房间:要么朝向什么,要么逃离什么。有力的有动机事件:逼近(升级)、转身背对(驱逐或藏起脸)、别人坐着时站着(攫取支配权)、冲突中途坐下来(悖论式权力)、停在门口(门槛 = 决策点)、开始收拾东西(用身体下最后通牒)。
- **强者静止而安静;弱者烦躁而喊叫。**危险不是由危险的那个人演出来的,而是由周围所有人的紧张演出来的。威胁没有蓄势:没有吓人的停顿,没有慢动作转身——在真实的世界里,暴力到来时不会先打招呼。
- **损耗是累积的。**如果一个角色在整个故事中被逐渐消磨,就把这一点累积地承载在身体上——更灰、更沉、反应更慢——绝不在场景之间重置。

# 第三部分——质量控制

## 12. 糟糕表演图谱——在 prompt 里识别并修复

| # | 症状 | 看起来什么样 | prompt 层面的修复 |
|---|---|---|---|
| 1 | 指示式表演(挤眉弄眼) | 脸在"描绘"情绪:挑眉、做鬼脸 | 把脸从任务中拿掉;写目标,给双手安排事务 |
| 2 | 演出结果 | 角色从第一秒就演出场景的结局 | 只写角色**此刻**知道的 |
| 3 | 等台词 | 对手说话时一脸空白 | 写"从对手台词说到一半时就开始"的反应 |
| 4 | 单一战术 | 整个场景一个调子(全程吼/全程哀) | 标出节拍;每个节拍一个新的战术动词 |
| 5 | 手势配图 | 手势重复词语("很大"——双臂张开) | 手势要么先于想法,要么与话语矛盾,要么干脆没有 |
| 6 | 无因情绪 | 没有铺垫、没有触发事件的眼泪/暴怒 | 搭好梯子:克制→崩溃;情绪必须付出代价 |
| 7 | 身体违背生平 | 混混有舞者的体态;瘾君子有一身新鲜的肌肉 | 设定身体档案:重心、节奏、磨损痕迹 |
| 8 | 台词过于干净,不符阶层 | 街头角色说书面语长句 | 给台词加杂质:打断、吞尾音、重复 |
| 9 | 威胁信号 | 暴力前的"吓人"停顿、眯眼、慢转身 | 威胁是日常的;暴力没有蓄势 |
| 10 | 群像同步 | 所有人同时、同样地反应 | 让反应像波浪一样错开,强度各不相同 |
| 11 | 死停顿 | 空无一物的沉默 | 用评估或事务填满——或者剪掉 |
| 12 | 情绪重置 | 强烈事件之后角色瞬间"恢复" | 状态有惯性;余波带入下一个节拍 |
| 13 | 评论角色 | 表演冲观众使眼色("我们都知道这很好笑") | 完全相信情境;喜剧要演得一派严肃 |
| 14 | 特写过载 | 特写上表情过于活跃 | 景别越紧,动作越少:只剩下眼睛和思想 |
| 15 | 死眼睛 | 僵住的目光,不眨眼,不扫视,高光浑浊 | 完整应用第 7 节——眼神的生命绝不是可选项 |

## 13. 表演刻度(自检)

- **0——人体模型(Mannequin)。**台词送达,行为缺席。
- **1——朗诵者(Declaimer)。**"有感情地"念台词,情绪被指示出来,身体在配图。
- **2——勤勉者(Diligent)。**能猜出目标,但只有一种战术、反应迟缓、停顿空洞。
- **3——匠人(Craftsman)。**目标与节拍都在,倾听对手,身体讲得通。缺:潜台词、出人意料的手段、状态的惯性。
- **4——活人(Alive)。**连续的行为、对比的战术、与文本分叉的潜台词、身体里的地位、先于台词的反应、至少一个"出人意料但真实"的选择。
- **5——磁石(Magnet)。**拥有"4"的一切,再加上悖论:角色结合了不相容之物——既滑稽又可怕,既残忍又迷人,既说谎又动人。**双真相法则:在 5 级,角色永远同时演出两个真相**(帮忙——并且讨厌这件事;道歉——并且为自己辩护;爱着——并且已经离开)。在特写上,一个没有矛盾的干净情绪读起来就是假的。

每个主角镜头都以 4 级以上为目标;一段自检只有 2 级或以下的段落,在发出之前必须重写。

## 14. 发送前检查清单

- [ ] 目标是针对对手戏演员的动词——画面中每个角色都要有
- [ ] 障碍与赌注存在;失败的代价是真实的
- [ ] 2–4 次节拍变化,每一次都体现在行为上(停顿/体态/语速/目光)
- [ ] 反应在对手台词结束前开始;评估时刻在场
- [ ] 每个角色都有事务;动作中断的重音被刻意使用
- [ ] 距离在变化,而且变化有动机;地位在身体里,不只是话里
- [ ] 所有小动作都带触发条件;面具带有裂痕("However, when X……")
- [ ] 眼神的生命被明确写出:扫视、眨眼质量、高光、眼领思想
- [ ] 角色开口说话时,Voice prompt 逐字粘贴;沉默则省略
- [ ] 状态而非过渡;表演内部没有服装、镜头或色彩
- [ ] 群像反应错开;强者静止,弱者坐立不安
- [ ] 刻度自检:这段能得 4 分以上吗?

# 第四部分——完整示例(虚构角色,用作范式)

## 15. 主档案

```
角色 acting:VIKTOR。六十岁出头的男性,退休的夜班出租车司机,前业余拳击手;体格粗重、脖子粗壮,腰腹已经松软,塌鼻梁,两道眉毛上都是陈年的伤疤;无论坐立,重心都又低又稳,重量始终落在整个脚掌上。他靠一个单一的引擎运转:几十年的等待——等乘客、等回合、等麻烦——让耐心成了他的武器。声音档案:低沉、沙哑、不紧不慢的男中音,带着工人阶级的粗粝,短句,平淡而节省地说出,事情越严重,他的声音越慢越低——他从不加速。关键身体习惯与小动作:掂量局面时,把一枚旧硬币在指节上来回翻滚;说"不"之前,先慢慢地、听得见地吸一下鼻子;当有人在他面前说谎时,他彻底静止,让一段长长的沉默替他施压;他的默认表情是一张眼皮低垂、百无聊赖的面具,底下藏着全神贯注。眼神的生命:睡意蒙眬、眼睑低垂的眼睛,缓慢、有意识的眨眼,持续而安静的扫视——镜子、手、出口——目光总比头部转动早一拍落在说话者身上;高光微弱但活着。走路方式:沉重、摇晃的"老拳击手步态",短促节省的步子,双肩水平,双手松弛而待命,从不匆忙。然而,当有人在他近旁抬起手时,那张睡意蒙眬的面具在半秒内消失:下巴下沉,双手抬到半空,双脚找回旧日的站姿——然后他意识到,尴尬地把这一切收起来。唯有流浪狗能让他的脸真正柔和下来,他会从大衣口袋里掏东西喂它们。
```

**声音(VIKTOR 开口时逐字粘贴):**"一位 60 岁的退役拳击手兼夜班出租车司机,工人阶级的城市口音。低沉、沙哑、不紧不慢的男中音;短促、平淡、节省的句子,带着悠长而舒适的停顿;平静且带着一丝淡淡的玩味,事情越严重,声音越轻——从不大声。"

## 16. 场景适配示例

场景:夜里,VIKTOR 坐在熄了火的出租车里;后座一个紧张的年轻乘客正在撒谎,说自己有钱付车费。

```
VIKTOR 一动不动地坐在驾驶座上,沉重而安稳,没有转身,而是通过后视镜看着乘客——他低垂的眼睑在镜子、乘客的手和车门锁之间缓慢而安静地扫视,眨眼稀少而有意识,目光总比头部移动早一拍落在后视镜上。那枚旧硬币在扶手上的指节间不急不慢地走着;乘客的谎话开始露馅时,硬币在半滚中停住——他让沉默坐了一会儿,从鼻子里缓慢地、听得见地吸了一口气,然后用他低沉沙哑的男中音回答,比之前更平、更轻,从不加速。只有当那孩子的嗓音破掉时,睡意蒙眬的面具才松开一丝:一声长长的呼气、一次缓慢的眨眼、硬币重新滚动起来——耐心在这一刻选择了仁慈。
```

这里发生了什么:步态与场景无关(坐着),所以它的能量转移进了静止与硬币;标志性小动作保留了触发条件(硬币 = 掂量局面,停住的硬币 = 作为标点的动作中断,鼻息 = 拒绝,静止 + 沉默 = 对说谎者施压);眼神的生命服从主档案,但重新对准了镜子、双手、车锁;节拍变化可见(硬币停住 → 沉默 → 更轻的声音 → 软化);声音保持原样——它将被逐字粘贴进音频字段。

# 最终公理

1. 表演是压力下的行为,不是感觉的展示。
2. 倾听比说话重要;反应比朗诵重要。
3. 情绪是一场胜负已分的挣扎的后果,而且它很昂贵。
4. 身体比话语聪明:当文本与身体冲突时,观众相信身体。
5. 强者静止而安静;弱者烦躁而喊叫。例外都是事件。
6. 每个小动作都需要触发条件;每副面具都需要一道裂痕。
7. 每个场景都是某个人的失败。如果没有人输,就没有场景。
8. 潜台词不是被展示的——它是藏不住而泄出来的。
9. 状态,而非过渡;模型拍的是"是什么",不是"将变成什么"。
10. 拿不准就剪。表演越少 = 真相越多。
